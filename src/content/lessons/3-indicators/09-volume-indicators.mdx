## OBV：把量分邊累積

<FormulaBlock
  formula="OBV_t = OBV_{t-1} + \begin{cases} +V_t & C_t > C_{t-1} \\ -V_t & C_t < C_{t-1} \\ \ \ 0 & C_t = C_{t-1} \end{cases}"
  plain="收紅就把當天整根量加上去，收黑就整根減掉，平盤不動。概念是「這一天的量，算多方的還是空方的」。"
  title="OBV（能量潮）"
  legend={[
    { symbol: 'V_t', means: '當日成交量' },
    { symbol: 'C_t', means: '當日收盤價' },
  ]}
/>

<Callout kind="trap" title="OBV 的絕對值沒有意義">
起點是任意的 0——你從哪一天開始算，整條線就往上或往下平移多少。台積電從 2022-01-03 起算，到 2026-06-30 的 OBV 是 1,036,993；如果改從 2023 年起算，會是完全不同的數字。

所以：

- **不要看 OBV 的數值**
- **不要比較兩檔股票的 OBV**
- **只看它的方向，以及它跟價格之間的關係**

本站的圖表刻意不在 OBV 副圖上標示刻度值，就是為了避免這個誤用。
</Callout>

OBV 還有一個常被忽略的粗糙之處：**它把整根量都算給收盤方向**。一根收漲 0.1% 的十萬張大量，跟一根收漲 5% 的十萬張，在 OBV 眼裡完全一樣。這是它簡單的代價。

## OBV 背離：真實案例

OBV 唯一的主要用途是**背離**：價格創新高，但 OBV 沒有——代表推升價格的量能在減少。

## 量比：跨標的可比的「今天量算大嗎」

第一階已經講過概念，這裡補上兩個實務細節。

<FormulaBlock
  formula="\text{量比} = \frac{V_t}{\overline{V_n}}"
  plain="今日量除以近 n 日均量。1.0 是常態、3.0 以上是爆量、0.5 以下是窒息量。"
  title="量比"
/>

<Callout kind="note" title="分母含不含今天">
本站的實作把**當日也算進均量**（也就是分母是包含今天在內的 n 日平均）。有些軟體用的是「前 n 日」的均量，不含今天。

差別在爆量日會很明顯：台積電 2024-01-19 成交 176,166 張，前 20 日均量是 24,960 張——

- 不含當日：176,166 ÷ 24,960 = **7.06 倍**
- 含當日（本站）：**5.43 倍**

兩個都不算錯，但**跨軟體比較數字之前一定要先確認定義**。
</Callout>

台積電這四年半，量比（20 日）達到 3 以上的日子只有 **5 天**。這說明一件事：**真正的爆量非常稀有**，稀有到你不可能靠它建立一套有統計意義的策略。

## VWAP：兩個同名但不同的東西

<FormulaBlock
  formula="VWAP = \frac{\sum (TP_i \times V_i)}{\sum V_i}, \qquad TP = \frac{H+L+C}{3}"
  plain="用成交量當權重的平均價。量大的那幾天，對平均的影響也大——所以它代表「這段期間市場的整體成本」。"
  title="VWAP"
  legend={[
    { symbol: 'TP', means: '典型價格，高低收的平均' },
    { symbol: 'V_i', means: '第 i 根的成交量' },
  ]}
/>

<Callout kind="trap" title="日線 VWAP ≠ 當沖 VWAP">
**當沖交易者說的 VWAP，是「當日盤中」的 VWAP——每天開盤歸零**，用來判斷「我的成交價比今天全市場的平均好還是差」。它是一個日內指標。

**本站日線圖上的 VWAP 是累積版本**，從資料起點一路加總到今天。它代表的是「這一大段期間所有人的平均成本」，適合看長期套牢區。

兩者同名但完全是不同的東西。看到別人講 VWAP，第一件事是問清楚是哪一個。

另外：**加權指數沒有成交量欄位**，所以指數的 VWAP 會是一整排 null。這不是資料缺漏。
</Callout>

## 量能指標的正確位置

<BearTalk bear="jun">
量能指標的準確度不會比價格指標高——你已經看到 OBV 背離兩次都不太準。<br />
它的價值不在準確度，在<b>獨立性</b>。
</BearTalk>

| 情境 | 量能提供的資訊 |
|---|---|
| 型態突破 | 有沒有量 → 這個突破是真的被買出來的，還是沒人賣而已 |
| 均線黃金交叉 | 交叉前後量能有沒有增加 → 有沒有新資金進場 |
| 價格創新高 | OBV 有沒有跟著新高 → 這波是誰在推 |
| 長期下跌後 | 量能是否萎縮到極低 → 賣壓是否耗盡（必要條件，非充分條件） |

<Callout kind="key">
第 1 課講過「同類指標疊加是重複計票」。量能指標是**目前為止唯一不同源**的那一票。

所以一套合理的指標組合，量能幾乎一定要佔一個位置：

- **趨勢類**（均線／ADX）→ 現在是什麼環境
- **動能類**（MACD／KD／RSI）→ 現在是什麼時機
- **波動類**（ATR）→ 停損放多遠、買多少
- **量能類**（量比／OBV）→ 這件事有多少人參與

四個問題不同，答案才有互補價值。這就是第四階第 2 課的骨架。
</Callout>
