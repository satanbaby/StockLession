## 它只是平均成本

<FormulaBlock
  formula="MA_n = \frac{Close_{t} + Close_{t-1} + \cdots + Close_{t-n+1}}{n}"
  plain="把最近 n 天的收盤價加起來除以 n。就這樣，沒有第二層意思。"
  title="簡單移動平均（SMA）"
  legend={[
    { symbol: 'n', means: '週期，例如 20 就是 20 個交易日' },
    { symbol: 'Close_t', means: '第 t 天的收盤價' },
  ]}
/>

關鍵在於怎麼**解讀**這個數字：MA20 是「最近 20 天進場的人，平均買在哪裡」。

於是所有用法都可以從這一句推出來：

- 股價**在均線之上** → 這段期間買進的人平均是賺的 → 沒有解套賣壓 → 拉抬相對輕鬆
- 股價**在均線之下** → 平均是套牢的 → 每反彈到成本附近就有人想跑 → 均線變成壓力
- 股價**跌破均線** → 這群人由賺轉賠，心態改變

<Callout kind="key">
均線之所以常常「有效」，不是因為那條線有魔力，而是因為**很多人都在看同一條線**。當足夠多的人把 MA20 當作進出依據，它就真的變成了支撐或壓力。這是自我實現，不是物理定律——也因此，越多人看的週期（台股的 5、20、60、240）越有效。
</Callout>

台股常用的週期都有名字，因為它們對應真實的時間單位：

| 週期 | 俗稱 | 對應 |
|---|---|---|
| 5 | 週線 | 一週的交易日 |
| 20 | 月線 | 一個月 |
| 60 | 季線 | 一季 |
| 120 | 半年線 | 半年 |
| 240 | 年線 | 一年 |

## 三種平均：差在權重

<BearTalk bear="kong" mood="worried">
軟體上有 SMA、EMA、WMA 可以選……我該用哪個？
</BearTalk>

<BearTalk bear="jun">
它們的差別只有一個：**近期的價格佔多少權重**。SMA 每天一樣重；WMA 用等差級數加重近期；EMA 用等比級數，理論上把所有歷史都算進來，只是越久遠的權重越接近零。
</BearTalk>

<Callout kind="try">
把下面這張圖的「平均方式」切換看看，並且把週期從 5 慢慢拉到 120。你會看到兩件事同時發生：**線變得越來越平滑，也變得越來越慢**。
</Callout>

這裡沒有「哪個比較好」的答案，只有取捨：

- **EMA 反應快** → 轉折時較早給訊號 → 但盤整時假訊號也更多
- **SMA 較鈍** → 假訊號少 → 但真的反轉時你會晚幾天才知道

<Callout kind="note">
本站的 EMA 用「前 n 根的 SMA」當起始種子，而不是直接拿第一根收盤價。後者是很常見的實作偷懶，會讓前面幾十根 EMA 明顯偏離正確值——兩條不同週期的 EMA 相減（也就是 MACD）時，這個誤差會被放大。
</Callout>

## 為什麼均線一定落後

<BearTalk bear="duo" mood="thinking">
均線總是慢半拍，這是不是它的缺點？
</BearTalk>

<BearTalk bear="jun">
不是缺點，是**它的定義**。平均就是把過去 n 天混在一起，你不可能同時要求它「代表過去 n 天」又「反映今天」。這兩件事在數學上互斥。
</BearTalk>

所有想「消除落後」的努力，本質上都是在減少平均的樣本數，也就是換回更多雜訊。落後與雜訊是同一條軸的兩端，你只能選位置，不能兩者都要。

<Callout kind="key">
理解這一點，就不會再去尋找「不落後的均線」。該問的問題不是「怎麼消除落後」，而是「**這次的決策，我願意用多少落後換多少確定性**」。做長線的人可以接受季線的遲鈍，做短線的人只能接受 5 日線的吵雜。
</Callout>

## 黃金交叉，實際上賺不賺？

這是本課最重要的一段。

「MA20 向上穿過 MA60 叫黃金交叉，買進；向下穿過叫死亡交叉，賣出」——這大概是流傳最廣的技術分析法則。我們直接用台積電 2022 年初到 2026 年 6 月的真實日線，把每一次交叉都算出來。

六次完整的「黃金交叉買進、死亡交叉賣出」，結果是：

| 進場 | 出場 | 報酬 |
|---|---|---|
| 2022-08-12　517 | 2022-09-19　467 | **−9.7%** |
| 2022-11-25　498 | 2023-04-25　498 | ±0.0% |
| 2023-05-30　566 | 2023-08-14　541 | **−4.4%** |
| 2023-11-06　550 | 2024-08-16　969 | **+76.2%** |
| 2024-10-08　1010 | 2025-03-05　1020 | +1.0% |
| 2025-05-22　982 | （尚未出場）2410 | **+145.4%** |

三勝三敗，累積報酬 **+277.0%**。

聽起來很棒——直到你看這個數字：同一段期間**什麼都不做、單純買進持有**的報酬是 **+281.9%**（631 → 2410）。

<BearTalk bear="duo" mood="shocked">
欸？忙了四年半，還輸給躺著不動？
</BearTalk>

<BearTalk bear="kong" mood="worried">
而且中間還要一直盯盤、一直下單、一直付手續費跟證交稅……
</BearTalk>

<BearTalk bear="jun">
更值得注意的是報酬的分布：六筆裡有四筆是虧損或幾乎沒賺，全部的獲利都來自那兩筆抱得夠久的大波段。這不是均線的失敗，這是<b>順勢策略的本質</b>——它靠少數幾次大賺覆蓋多數次小賠。如果你在連續三筆小賠之後放棄，就正好錯過那一筆。
</BearTalk>

<Callout kind="trap">
這個結果**不代表均線沒用**，也不代表買進持有比較好——只用一檔股票、一段期間、一組參數得出的結論，本身就不該被過度推廣（這正是進階篇「過度最佳化」要談的）。

它真正的意義是：**任何宣稱簡單交叉法則能穩定獲利的說法，都應該被要求拿出實際數字**。而當你自己算過一次之後，就不會再輕易相信別人的印象。
</Callout>

那均線該怎麼用？合理的定位是**濾網與框架**，而不是進出訊號：

- 用長天期均線（季線、年線）判斷**現在是多頭還是空頭環境**，決定要不要做多
- 用均線的**排列**（短期在上＝多頭排列）確認趨勢一致性
- 用乖離率判斷**現在是不是追高的好時機**
- 進出場的精確時點，交給其他工具與風險管理
