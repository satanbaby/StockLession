## 先看一眼：KD 線圖在說什麼

<KdAnatomy />

<Callout kind="key" title="先記住一句話就夠了">
**KD 描述的是「收盤最近都靠近區間的哪一邊」，不是預測明天一定漲或一定跌。**

看圖時依序問三件事：K、D 現在位於高檔還是低檔？正在往上還是往下？K 有沒有穿越 D？至於該不該買賣，還要等後面判斷市場正在盤整還是走趨勢。
</Callout>

## RSV：收盤站在區間的哪裡

KD 的一切都從一個簡單的問題開始：**今天的收盤價，落在最近 n 天的高低區間中的什麼位置？**

<FormulaBlock
  formula="RSV = \frac{C_t - L_n}{H_n - L_n} \times 100"
  plain="今天收盤減掉近 n 天最低，除以近 n 天的高低差。收在區間最高點就是 100，最低點就是 0，正中間就是 50。"
  title="未成熟隨機值 RSV"
  legend={[
    { symbol: 'C_t', means: '今天的收盤價' },
    { symbol: 'H_n', means: '近 n 天（含今天）的最高價' },
    { symbol: 'L_n', means: '近 n 天的最低價' },
    { symbol: 'n', means: '回顧期間，台股慣例 9' },
  ]}
/>

這個設計背後有個很實際的觀察：**上漲趨勢中，收盤價傾向落在當日與近期區間的高檔；下跌趨勢中則傾向落在低檔**。RSV 就是把這個觀察量化。

## 兩次平滑：K 與 D

RSV 直接畫出來會非常跳動——一天之內從 90 掉到 20 是家常便飯，根本沒辦法用。所以要平滑：

<FormulaBlock
  formula="\begin{aligned} K_t &= \tfrac{2}{3} K_{t-1} + \tfrac{1}{3} RSV_t \\[4pt] D_t &= \tfrac{2}{3} D_{t-1} + \tfrac{1}{3} K_t \end{aligned}"
  plain="今天的 K＝昨天的 K 佔三分之二、今天的 RSV 佔三分之一。D 再對 K 做一次同樣的事。所以 D 一定比 K 慢，K 一定比 RSV 慢。"
  title="K 與 D"
  legend={[
    { symbol: '⅔ / ⅓', means: '對應「3 日平滑」，一般寫成 KD(9,3,3) 的後兩個 3' },
    { symbol: 'K₀, D₀', means: '初始值，台股一律用 50' },
  ]}
/>

<Callout kind="tw" title="為什麼初始值是 50">
遞迴公式需要一個起點。台股所有主流看盤軟體都用 **50**（也就是「中性、無資訊」），而不是第一個 RSV。這個選擇會影響前面十幾根的數值——如果你自己寫程式算 KD 卻跟券商軟體對不起來，初始值是第一個該檢查的地方。

本站的實作也用 50，並且有單元測試鎖住這個行為。
</Callout>

<Callout kind="try">
下圖可以調整三個參數。試試看把「RSV 期間」從 9 拉到 30——你會看到 KD 的波動範圍明顯縮小，觸及 80／20 的次數大幅減少。**訊號變少不代表變準，只是門檻變高了。**
</Callout>

## 標準用法（以及它們的前提）

在**盤整**的行情裡，KD 相當好用：

- **K 向上穿越 D**（黃金交叉），特別是發生在 20 以下時 → 買進參考
- **K 向下穿越 D**（死亡交叉），特別是發生在 80 以上時 → 賣出參考
- K 值 > 80 → 超買區；< 20 → 超賣區

這些用法都建立在同一個假設上：**價格會在一個區間內來回**。所以收在區間頂端就該回頭，收在底端就該反彈。

問題是——這個假設在趨勢行情裡完全不成立。

## 鈍化：KD 最重要的一課

<BearTalk bear="jun">
KD 的值域被鎖死在 0 到 100 之間。這是它的優點（好比較），也是它致命的限制：<b>當股價持續創新高，收盤天天都站在區間頂端，RSV 就天天接近 100，K 值也就一直卡在 80 以上下不來。</b>
</BearTalk>

這就叫**高檔鈍化**。指標沒有壞掉，它只是誠實地回報「收盤仍在區間頂端」——但如果你把 80 讀成「該賣了」，就會在趨勢剛啟動的地方下車。

來看真實的數字。台積電在 2025 年底到 2026 年初，出現了這四年半以來最長的一次高檔鈍化：

**K 值在 80 以上連續停留 19 個交易日**（2025-12-29 至 2026-01-23）。這段期間股價從 1530 漲到 1770，**上漲 15.7%**。

<BearTalk bear="duo" mood="shocked">
所以如果我第一天看到 K 值 80 就賣掉……我就錯過了 15.7%？
</BearTalk>

<BearTalk bear="jun">
是的。而且反過來也一樣：同一檔股票在 2025 年 2 月底到 3 月中，K 值在 20 以下連續 14 天，那段期間股價從 1040 <b>跌到 952</b>。「超賣就買」在那裡會讓你一路往下接。
</BearTalk>

<Callout kind="trap">
**超買不等於該賣，超賣不等於該買。** 正確的讀法是：

- 超買 = 「買方力量非常強」——在**盤整**中意味著即將回頭，在**趨勢**中意味著趨勢很健康
- 超賣 = 「賣方力量非常強」——同理

同一個數字，在不同的市場狀態下意思相反。這就是為什麼 KD 幾乎不該單獨使用。
</Callout>

## 那怎麼辦：先判斷環境

既然 KD 的訊號在盤整與趨勢中意義相反，那麼**先判斷現在是哪一種**就成了使用它的前提。常見的做法是加一層趨勢濾網：

| 環境判斷 | 怎麼看 | KD 訊號該怎麼讀 |
|---|---|---|
| 盤整 | ADX < 20、均線糾結、價格在區間內來回 | 照標準用法：超買賣出、超賣買進 |
| 上升趨勢 | 均線多頭排列、ADX 上升 | **只做多方訊號**。超買忽略，回檔到超賣區反而是加碼點 |
| 下降趨勢 | 均線空頭排列 | **只做空方訊號**。超賣忽略 |

<BearTalk bear="kong" mood="thinking">
所以不是 KD 不好用，是我用它的時候少問了一個問題：「現在是盤整還是趨勢？」
</BearTalk>

<BearTalk bear="jun">
對。這也是進階篇「指標組合」的核心概念——<b>用趨勢類指標決定要不要聽動能類指標的話</b>。單一指標從來就不是為了獨立決策而設計的。
</BearTalk>
