## 先問「最多賠多少」

專業的順序是這樣：

1. **這一筆最多願意賠多少？**（風險預算，通常是總資金的 1~2%）
2. **停損放哪？**（由型態與 ATR 決定，不是由你的忍耐度決定）
3. **每股風險 = 進場價 − 停損價**
4. **可買股數 = 風險預算 ÷ 每股風險**

<FormulaBlock
  formula="\text{股數} = \frac{\text{總資金} \times \text{單筆風險比例}}{\text{進場價} - \text{停損價}}"
  plain="分子是「我最多接受賠掉多少錢」，分母是「每一股會賠多少」。相除就是能買幾股。"
  title="部位大小公式"
  legend={[
    { symbol: '單筆風險比例', means: '一般建議 1~2%' },
    { symbol: '進場價 − 停損價', means: '每股風險，由停損位置決定' },
  ]}
/>

<Callout kind="key">
這個公式有一個很反直覺但極其重要的性質：

**停損放得越遠，能買的張數越少。**

很多人以為「停損放寬 = 承擔更多風險」。錯了——只要同時把部位縮小，**風險金額完全一樣**。停損距離與部位大小是一組配套，調一個就要調另一個。

這也解釋了上一課為什麼說「順勢系統的進場點在回檔不在突破」：回檔進場的停損距離短，同樣的風險預算下可以買更多。
</Callout>

## 動手算

<RiskCalculator />

<Callout kind="try">
預設是總資金 100 萬、單筆風險 2%、進場 100、停損 93、目標 121，算出來是 **2 張**、停損時實賠 **14,000 元**。試三組改動：

1. **停損從 93 改成 85**（距離變兩倍）→ 張數掉到 **1 張**，但停損時實賠變成 15,000 元，**幾乎沒變**。這就是配套的意思：停損放遠、部位縮小，風險金額守住。
2. **單筆風險從 2% 改成 5%** → 張數變 **7 張**、實賠 49,000 元。看起來很爽，但把下一節那張回本表看完再決定。
3. **目標價從 121 改成 107** → 盈虧比從 1:3 掉到 1:1 ，右下角的提示會告訴你需要多高的勝率才能打平。
</Callout>

## 為什麼是 1~2%：虧損的不對稱

<BearTalk bear="kong" mood="worried">
1% 太少了吧？賺的時候也才 1%？
</BearTalk>

<BearTalk bear="jun">
1% 是<b>虧的時候</b>賠 1%，賺的時候可以是 2%、3%。而且你必須知道虧損有多難補。
</BearTalk>

| 虧損幅度 | 要漲多少才回本 |
|---|---|
| −10% | +11.1% |
| −20% | +25.0% |
| −30% | +42.9% |
| −40% | +66.7% |
| **−50%** | **+100%** |
| −70% | +233% |

<FormulaBlock
  formula="\text{回本所需漲幅} = \frac{1}{1 - L} - 1"
  plain="虧損 L 之後，剩下的本金要漲這麼多才回得到原點。虧損越大，這個數字加速上升——這是除法的性質，不是心理作用。"
  title="回本公式"
/>

<Callout kind="trap" title="連續虧損比你想像的常見">
一套勝率 50% 的系統，連續虧 5 次的機率是 $0.5^5 = 3.1\%$。聽起來很低——但如果你一年交易 100 次，**至少出現一次連五敗的機率超過 95%**。

用單筆 2% 算，連五敗是 −9.6%（複利），還在可控範圍。
用單筆 10% 算，連五敗是 **−41%**，需要漲 69% 才回本。

**風險控管處理的不是平均情況，是最壞情況。** 平均情況不會讓你出局，尾端事件才會。
</Callout>

## 停損要放在「型態被否定」的地方

<BearTalk bear="duo" mood="thinking">
那停損到底怎麼決定？
</BearTalk>

<BearTalk bear="jun">
問一個問題：<b>跌到哪裡，我當初進場的理由就不成立了？</b><br />
那裡就是停損，不是你能忍受的虧損金額。
</BearTalk>

| 進場理由 | 停損位置 |
|---|---|
| 突破頸線 | 頸線之下 |
| 回檔到 MA20 不破 | MA20 之下，或這波回檔的最低點 |
| 支撐區有長下影線 | 那根 K 棒的最低點 |
| 看漲吞噬 | 吞噬那一根的最低點 |
| 型態突破 | 型態邊界之內 |

然後用 **ATR 檢查距離合不合理**：

- 停損距離 **< 1.5 倍 ATR** → 太緊，會被日常波動掃到。往外挪，或換一個更好的進場點
- 停損距離 **> 3.5 倍 ATR** → 太遠，代表這個進場點不好（追高了）。等回檔

<Callout kind="key">
**如果算出來的停損距離太遠，正確的反應是「不進場」，不是「把停損拉近」。**

把停損硬拉到一個沒有結構意義的位置，你只是保證自己會在一次正常波動裡被掃出場，然後看著股價照原本的劇本走。這是新手最痛的一種虧損，因為方向明明看對了。
</Callout>

## 盈虧比與勝率的關係

<FormulaBlock
  formula="RR = \frac{\text{目標價} - \text{進場價}}{\text{進場價} - \text{停損價}}"
  plain="賺的時候能賺多少，除以賠的時候會賠多少。這是進場前就能算出來的數字。"
  title="盈虧比"
/>

打平所需的最低勝率：

<FormulaBlock
  formula="p_{\min} = \frac{1}{1 + RR}"
  plain="盈虧比越高，需要的勝率越低。這就是為什麼「賺大賠小」比「常常賺一點」重要。"
  title="損益兩平勝率"
/>

| 盈虧比 | 打平所需勝率 |
|---|---|
| 1 : 1 | 50% |
| 1 : 1.5 | 40% |
| **1 : 2** | **33.3%** |
| 1 : 3 | 25% |
| 1 : 5 | 16.7% |

<BearTalk bear="jun">
第一階講的甲乙兩套方法還記得嗎？乙的勝率只有 35%，但盈虧比是 4:1，所以它遠超過 20% 的打平門檻。<br />
<b>盈虧比決定你「需要多準」，勝率決定你「實際多準」。</b> 兩個都要知道才能判斷。
</BearTalk>

<Callout kind="tw" title="別忘了交易成本">
台股來回成本約 **0.585%**（買賣手續費各 0.1425% ＋ 賣出證交稅 0.3%；券商折讓後大約 0.4~0.5%）。現股當沖的證交稅減半為 0.15%。

對一筆預期賺 15% 的波段交易，0.5% 只是零頭。但對一筆預期賺 2% 的短線交易，**它吃掉四分之一的利潤**。

把成本算進盈虧比：目標 +2%、停損 −1%，看起來是 1:2；扣掉 0.5% 成本後變成 +1.5% : −1.5%，也就是 **1:1**——打平勝率從 33% 跳到 50%。**交易越頻繁，成本越可能是決定生死的那一項。**
</Callout>

## 加碼與停利

**加碼**只有一個安全的做法：**只在已經有獲利、而且能把整體停損上移到成本之上時加**。在虧損的部位上加碼（攤平）會同時放大部位與虧損，是爆倉最常見的路徑。

**停利**有三種常見做法，各有取捨：

| 做法 | 優點 | 缺點 |
|---|---|---|
| 固定目標價 | 簡單、可事先算盈虧比 | 大行情會提早下車 |
| 移動停損（跟著 MA 或 ATR 走） | 抓得到大波段 | 一定會從最高點回吐一段 |
| 分批出場 | 心理壓力小 | 兩邊都不極致 |

<Callout kind="key">
沒有最好的做法。但有一個原則：**進場之前就要決定用哪一種**。

在部位裡才開始想「要不要停利」，決定會被損益數字影響——賺錢的時候想抱久一點、虧錢的時候想再等等。那不是判斷，是情緒。
</Callout>
