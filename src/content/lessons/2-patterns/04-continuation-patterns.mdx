## 整理型態的共同語言

反轉型態講的是「趨勢要結束了」，整理型態講的是「趨勢在休息」。統計上，**整理型態往原方向突破的機率高於反轉**——但這句話有個陷阱：那是**事後**統計。在突破發生之前，你並不知道它會往哪邊走。

所有整理型態都共用同一套量能節奏：

<Callout kind="key">
**進入整理 → 量能萎縮 → 突破時量能放大。**

量縮是整理型態的必要條件。如果一段「盤整」期間量能不但沒縮還放大，那多半不是整理，是**在換手**——籌碼正在從一批人手上轉到另一批人手上，而換手的結果可能是任何方向。
</Callout>

## 上升三角：壓力不動，地板抬高

四次觸及壓力的日內最高價分別是 **101.0、101.5、101.3、101.5**——同一條線。而三次回檔的低點是 **84.8 → 88.2 → 92.6**，每次都更高。

背後的故事：**有人在 100.5 掛了一大批賣單慢慢賣，但買方越等越急，願意出的價格一次比一次高。** 當賣單被吃完，價格就會直接跳上去。

**上升三角偏多**（下降三角是它的鏡像，偏空）。**對稱三角**則是高點下降、低點上升同時發生，那種不帶方向——它只告訴你「波動在收斂，快變盤了」。

## 旗形：急漲之後的小口喘息

    { from: { time: '2024-03-06', price: 80.1 }, to: { time: '2024-03-26', price: 79.1 } },
  ]}
  title="多頭旗形的原型"
  caption="旗桿從 51.5 拉到 89.4，接著在一個小幅下傾的窄通道裡整理，量能萎縮到旗桿期的一半以下，然後續攻。"
/>

旗形的三個特徵：

1. **旗桿要陡。** 前面那段急漲是必要條件，沒有旗桿就沒有旗形
2. **旗面要小。** 回檔幅度不超過旗桿的一半（這裡是 89.4 → 79.1，回了 27%）
3. **旗面要逆著趨勢傾斜。** 多頭旗形的旗面應該**向下**傾斜

<Callout kind="key">
第三點是關鍵。**如果急漲之後的整理是向上傾斜的，那不是旗形。** 那代表買方在高檔還在持續加價買進——聽起來很強，實際上往往是散戶追高的階段，後面接的是上升楔形（下一節）。

順著趨勢傾斜的整理不叫休息，叫**過熱**。
</Callout>

旗面如果不是通道而是收斂的小三角，就叫**三角旗形**。意義一樣。

  caption="兩條邊都往上，但下緣爬得比上緣快，通道越來越窄。每一波的漲幅：18 → 16 → 15 → 12 → 8。"
/>

<BearTalk bear="kong" mood="thinking">
高點在墊高、低點也在墊高……照定義這是上升趨勢啊？
</BearTalk>

<BearTalk bear="jun">
定義上是。但看那幾波的<b>幅度</b>：18、16、15、12、8。每推一次就少走一點。<br />
這叫「還在漲，但越來越推不動」。加上量能一路萎縮——這是漏氣，不是蓄力。
</BearTalk>

| | 多頭旗形 | 上升楔形 |
|---|---|---|
| 整理的方向 | **逆勢**（向下傾） | **順勢**（向上傾） |
| 波幅變化 | 旗面波動很小且均勻 | 一波比一波小 |
| 量能 | 旗面萎縮，突破放大 | 整段持續萎縮，跌破才放量 |
| 結局 | 往上續攻 | **往下** |
| 心理 | 獲利了結後重新集結 | 追價力量逐漸耗盡 |

<Callout kind="trap">
上升楔形是最容易被誤讀的型態，因為**它每一項條件單獨看都是多頭**：高點墊高、低點墊高、價格在均線上、趨勢線還沒破。

唯一的破綻在「**動能**」而不在「**方向**」。要看出它，你必須比較每一波的幅度，或者用一個直接量化動能的工具——那就是第三階的 MACD 與背離。
</Callout>

## 矩形：完全沒有方向資訊

  bars={rectangle.bars}
  synthetic
  height={330}
  priceLines={[
    { price: 80.5, label: '箱頂 80.5', dashed: true },
    { price: 66, label: '箱底 66', dashed: true },
  ]}
  title="矩形整理（箱型）的原型"
  caption="高低點都被兩條水平線框住，來回四趟。突破前，這個型態不提供任何方向資訊。"
/>

矩形最誠實：它明白告訴你「**市場現在沒有共識**」。多空在兩個價位之間拉鋸，誰都推不動誰。

它的價值在於**兩條邊界都是明確的操作依據**：

- 在箱底附近買、箱頂附近賣（區間操作），停損放在箱外
- 或者等突破再順著方向做，停損放回箱內

兩種都可行，但**不能混用**。最常見的虧損方式是「在箱底買進，突破箱頂後不賣、繼續抱，然後跌回箱內」——那是把兩套互相矛盾的計畫接在一起。

## 突破之後能走多遠：最小滿足點

<FormulaBlock
  formula="\text{目標價} = \text{突破價} \pm \text{型態高度}"
  plain="把型態最厚的地方量出來，從突破點往同方向投影一次。這是估算不是保證。"
  title="最小滿足點"
  legend={[
    { symbol: '型態高度', means: '矩形是箱頂減箱底；三角是最寬處的垂直距離；旗形是旗桿的長度' },
  ]}
/>

用上面那個矩形算：箱頂 80.5、箱底 66，高度 **14.5**。向上突破後的最小滿足點是 **80.5 + 14.5 = 95**。這組合成資料實際走到 **98.4**。

<Callout kind="note">
「最小滿足點」這個名字本身就在提醒你它的性質——它是**下限的估計**，不是目標，更不是預測。

實務上它的用途是**事前檢查風險報酬比**：如果最小滿足點只有 5%，而合理的停損要放 4%，那這筆交易的盈虧比只有 1.25，不值得做。**在進場之前就知道這件事，比事後才發現划不來有價值得多。**
</Callout>

## 什麼時候整理型態會失效

**一、假突破。** 尤其在量縮的突破。矩形的箱頂上方通常堆滿了停損單與突破單，主力用少量資金把價格推過去引發追價，然後反手賣出——這在流動性差的個股特別常見。

**二、時間太長。** 一個矩形整理了三個月很正常，整理了兩年就不叫整理了，那是新的趨勢（橫盤趨勢）。一般的參考是**整理時間不宜超過前一段趨勢的長度**。

**三、看錯尺度。** 日線上的旗形只能推導出日線級別的目標。用日線的型態去期待週線級別的漲幅，是尺度錯配。
